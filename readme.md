🌍 Ecotourgame ♻️
Bem-vindo ao Ecotourgame, um jogo educativo onde o objetivo é arrastar os itens para as lixeiras corretas e aprender mais sobre reciclagem! 🎮🌱

📌 Funcionalidades
✅ Arraste e solte os itens de lixo nas lixeiras corretas
✅ Pontuação dinâmica: ganhe pontos ao acertar e perca ao errar
✅ Sons específicos para cada tipo de material reciclável
✅ Música de fundo (com opção de ativar/desativar)
✅ Design responsivo para diferentes dispositivos

🚀 Como Jogar
1️⃣ Arraste um item de lixo e solte-o sobre a lixeira correspondente.
2️⃣ Se estiver correto, você ganha pontos! Se errar, perde pontos.
3️⃣ Recicle corretamente o máximo de itens possível para aumentar sua pontuação.

🛠️ Tecnologias Utilizadas
HTML, CSS, JavaScript
GitHub Pages (para hospedagem)
Manipulação de áudio para feedback sonoro
